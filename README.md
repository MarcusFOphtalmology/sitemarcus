# Site do Dr. Marcus Felipe Jardim do Nascimento

Site de página única (HTML, CSS e JavaScript puro, sem build), em português do Brasil.

## Estrutura
- `index.html`: página completa
- `css/style.css`: estilos e tokens de design
- `js/main.js`: menu móvel
- `assets/fotos/`: fotos em uso
- `assets/reserva/`: fotos não usadas no momento

## Publicar no GitHub Pages
1. Crie um repositório no GitHub (ex.: `site-medico`).
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Em Settings > Pages, escolha "Deploy from a branch", branch `main`, pasta `/ (root)`.
4. O endereço será `https://SEU-USUARIO.github.io/site-medico/`.
